# Slop Audit — tests/, tools/, build, docs, repo hygiene

**Date:** 2026-09-20
**Scope:** `tests/*.c`, `tools/`, `meson.build`, `meson_options.txt`, `config/metadesk.toml.example`, `docs/`, `SPEC.md`, `README.md`, `AGENTS.md`, `.gitignore`, `.beads/`
**Explicitly out of scope:** `src/` (read only to verify claims about what tests/docs/config assert)
**Method:** every finding below was verified by reading the referenced file at the referenced lines. Build-option claims were cross-checked against `build/meson-info/intro-buildoptions.json`. The FIPS address test vectors were independently recomputed in Python. Tracker claims were cross-checked against `bd stats` and the working tree.

**Headline:** the suite is green because it is *structurally incapable of being red* in several places, not because the behaviour is pinned. 23 of 29 test binaries verify exclusively through bare `assert()` while their `main()` returns a hardcoded `0`; two more subsystems (input dispatch, a11y backend) assert nothing at all on a normal developer or CI machine. Separately, the default build (`client=true`) cannot configure from a fresh clone, and the example config file is read by nothing.
