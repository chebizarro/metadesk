# Slop Audit — FIPS/NAT layer and binaries

**Date:** 2026-09-20
**Scope (exclusive):** `src/fips-nat/` (main.c, publish.c/h, punch.c/h, stun.c/h, turn.c/h, fipsnat_ipc.c/h), `src/core/fips_addr.c/h`, `src/core/fips_control.c/h`, `src/host/main.c`, `src/client/main.c`, `src/client/render.c/h`, `src/client/ui.cpp/h`.
**Premise:** the code works and tests pass. Everything below is code that is the *wrong shape*: a kludge standing in for a primitive that exists, or a pattern imposing avoidable maintenance cost.

Every finding names a concrete correct shape. Findings where I could not name one were dropped.

---

## Context

Three binaries (`metadesk-host`, `metadesk-client`, `fips-nat`) each hand-roll their own bootstrap: CLI parsing, signer selection, relay defaults, FIPS daemon health checks. `src/fips-nat/` hand-rolls STUN/TURN/hole-punching with three private copies of the same byte helpers. `src/client/` splits SDL ownership between two files that both think they own the event queue and the present call.

Two facts frame the whole audit:

1. **`config/metadesk.toml.example` has no reader.** A repo-wide search for `toml`, `config_load`, or any config parser across `src/` returns nothing. Relays, `stun_server`, `fips_port`, `host.port`, `bitrate` and `fps` are all documented in that file, and all six are hardcoded in C instead.
2. **Most of `src/fips-nat/` has no production caller.** `md_turn_send`, `md_turn_recv`, `md_turn_refresh`, `md_punch_peer`, `md_stun_discover`, `md_subscribe_nat_endpoint`, `md_fipsnat_ipc_cmd_discover`, `md_fipsnat_ipc_cmd_punch`, `md_fipsnat_ipc_cmd_shutdown` are referenced only by their own tests, and those tests only assert NULL-argument error returns.

## Verified as NOT problems

Checked against the brief; these are correct as written and should be left alone:

- **`nanosleep` retry loops** (`fips_control.c:284`, `client/main.c:395`) — both pass `&ts` as the remainder argument, so `nanosleep` decrements it on every `EINTR`. The loops are bounded by the original duration. Not a retry-without-budget.
- **`md_fips_control_wait_peer_ready` polling** — properly bounded by `deadline`, with per-request timeouts clamped by `md_fc_remaining_request_timeout`.
- **`md_punch_execute`'s ICMP-error suppression** (`punch.c:228-234`) — deliberately ignoring `ECONNREFUSED`/`ENETUNREACH`/`EHOSTUNREACH` is correct for hole punching, and the comment explains why.
- **`fips_addr.c` bech32 decoder** — hand-rolled, but it is the only bech32 decoder in the tree (`signer.c:467` delegates to it), so it is the shared module, not a duplicate.

## Recommended order

1. **Findings 2, 4, 8, 9** — deletion only, no behavior change, removes roughly 600 lines.
2. **Findings 6, 7** — restores the overlay's F1 toggle and Disconnect button, which are currently inert.
3. **Findings 10-13, 31** — the shared-bootstrap module; collapses three copies of relay/signer/FIPS-check logic into one.
4. **Findings 1, 21, 22, 25, 27** — config source and error-honesty.
5. **Finding 5** — decide TURN's fate: implement MESSAGE-INTEGRITY or delete the client. Do not leave a protocol client that cannot authenticate.
6. **Findings 14-19, 26, 28-30, 32** — mechanical cleanups.
